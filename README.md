# Ejercicios de mecánicas de gameplay en Python

## Descripción

En este repositorio se desarrollan cuatro secciones de ejercicios enfocados en el aprendizaje de los fundamentos de Python. Cada sección contiene diferentes laboratorios que permiten practicar el uso de variables, operadores, entrada de datos y operaciones matemáticas mediante situaciones relacionadas con el desarrollo de videojuegos.

## Contenido

- Variables.
- Operadores aritméticos.
- Ejercicios de mecánicas de gameplay.
- Documentación y explicación de operadores.

## Requisitos

Para ejecutar los ejercicios es necesario tener instalado Python 3.

Puede verificar la instalación con el siguiente comando:

```bash
python --version
```

## Ejecución

Ubíquese en la carpeta del proyecto y ejecute el ejercicio que desee. Por ejemplo:

```bash
python ejercicio1.py
```

En Windows también puede utilizar:

```bash
py ejercicio1.py
```

## Objetivo

El propósito de estos ejercicios es fortalecer la lógica de programación y familiarizarse con el uso de los operadores aritméticos, la entrada de datos y la resolución de problemas básicos mediante Python.
